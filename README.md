### Day 2: Basic Commands
- `ls -la`: list files (detailed + hidden files)
- `cd ~`: go to home directory
- `mkdir`: create folder
- `touch`: create empty file
- `cp`: copy
- `mv`: move or change name
- `rm`: delete
- `rm -r`: delete folder
